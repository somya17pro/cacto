# 🎯 GitHub Customer-Finding Links & Prospect Extraction Engine

Use this skill whenever asked to find leads, uncover high-intent B2B prospects, source founder contacts from GitHub, or execute cold outreach using public open-source signals.

---

## ⚡ How to Read GitHub Path Signals

- **`/network/dependents`**: Companies building on top of a project. They have existing budget and active software products in production.
- **`/stargazers`**: High-intent prospects shopping right now. They saved the repo because they are actively solving a problem.
- **`/issues`**: High-pain prospects whose tools or scrapers are breaking right now. They are ready to pay for a working solution.

## 🔍 Custom Niche Discovery Query Patterns

If none of the 16 repos match a specific niche, use these 3 GitHub search patterns:

1. **Topic Discovery**:
   `https://github.com/topics/YOUR-NICHE`
2. **Pain Point Discovery (Searching for alternatives)**:
   `https://github.com/search?q="alternative+to+TOOL"&type=issues`
3. **Explicit Hiring/Contracting Intent**:
   `https://github.com/search?q="looking+for"+YOUR-SERVICE&type=issues`

## 📧 4-Step Outreach Workflow

1. **Identify Prospect**: Click the organization or user profile on the target repo.
2. **Extract Facts**: Note their domain, founder name, tech stack, and primary product.
3. **Cross-Reference**: Find the founder or CTO on LinkedIn / Twitter.
4. **First-Line Personalization**:
   > *"Hey [Name], saw you're building on [Repo Name] for [Company Name]. We noticed..."*
